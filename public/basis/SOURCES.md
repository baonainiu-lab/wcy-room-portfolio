# Basis Universal decoder provenance

`basis_transcoder.js`, `basis_transcoder.wasm`, and `README.md` are copied byte-for-byte from this project's installed `three@0.172.0` package:

`node_modules/three/examples/jsm/libs/basis/`

Upstream snapshot: https://github.com/mrdoob/three.js/tree/r172/examples/jsm/libs/basis

The bundled README identifies the decoder's license as Apache 2.0 and credits Binomial LLC / Basis Universal. Its original text is preserved. `APACHE-2.0.txt` is the original license downloaded from https://raw.githubusercontent.com/BinomialLLC/basis_universal/master/LICENSE on 2026-09-24. `THREE-LICENSE.txt` retains the installed Three.js distribution's MIT license.

The files are served locally for Three.js `KTX2Loader`, using `setTranscoderPath('/basis/')`. They are not modified or fetched from a third-party runtime CDN.
