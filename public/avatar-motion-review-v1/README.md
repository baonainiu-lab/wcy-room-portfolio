# 人物动作关键帧预演 V1

本目录是独立的概念验收页，只展示四张静态人物关键帧与切换节奏。它不是视频、骨骼动画，也没有把人物接入正式作品集首页。

本地地址：`http://127.0.0.1:5173/avatar-motion-review-v1/index.html`。

## 文件

- `index.html`：无依赖预览页面，米白、墨蓝和橙色；初始停在动作 01。
- `motion-plan.json`：姿态、建议停留时长、顺序和后续三维约束。
- `poses.png`：由主任务放入的四格人物关键帧图；图片尚未准备好时，页面显示原因与重试按钮。

图片必须严格为 2×2 排列，没有沟槽或额外边框。顺序为左上 01、右上 02、左下 03、右下 04。四格保持同一人物比例、设备尺寸、机位、构图和脚底基线。页面用 `background-size: 200% 200%` 取四个象限，单格显示比例自动采用原图宽高比。

## 交互与节奏

点击四个动作按钮可直接查看；也可通过 Tab、Enter、Space 操作。按钮组另外支持方向键和 Home / End。手动选图会停止自动预演。

开启自动预演后，按 **01 → 02 → 01 → 03 → 01 → 04** 循环，各动作之间通过托举待机稳态转接。每次切换仅进行约 0.35 秒图片淡化。动作 01 / 02 / 03 / 04 的建议停留分别为 3.2 / 2.0 / 2.4 / 2.2 秒。

进入其他页面或后台时停止自动播放。启用系统“减少动态效果”时禁用自动播放，移除淡化动画，但保留手动查看。

## 后续三维动作要求

右手始终承托终端，左手仅在点触动作短暂接触屏幕；其余动作中左手与设备分离。双脚保持不动，重心只作小幅变化。不通过整张图片上下漂浮冒充呼吸动画。

正式三维需另行进行建模、绑定与动作制作。建议动作交叉混合用时 0.35–0.5 秒，并以托举稳态作为过渡中心，验证手掌与设备的接触、脚底稳定及动作结束恢复。

角色与动作仍待用户验收，本目录不构成人物建模或正式首页接入的完成证明。没有修改作品集源代码，也没有部署。
