# ambientCG marble source evidence

Material assets selected for room wall/cap V20 revision 4.

- White wall: [Marble005](https://ambientcg.com/a/Marble005).
- Black upper cap: [Marble002](https://ambientcg.com/a/Marble002).
- Official license: [CC0 1.0](https://docs.ambientcg.com/license/), checked 2026-10-01. Official page copy: `ambientcg-license.html`.
- Downloadable maps and material previews are covered. Modification and redistribution are permitted, including commercial use.
- Source metadata marks both as `PBRProcedural`: these are authored PBR textures, not claimed to be scans.
- Per-asset `*-SOURCE.json` records exact package URL, byte length and SHA256 for the package and every extracted file.
- No template license is changed. Authoring adjustments and actual Blender baking are recorded in the V20 scene recipe and release reports.
