# 开场终端停靠与光影 V7

2026-09-25。当前开场使用同一个真实 Blender 创作终端：欢迎页展开后沿连续 Bézier 路径落到房间书桌，成为可交互的永久桌面资产。替代 V6 的终端缩小消失方案。仅本地预览，用户视觉验收仍待反馈。

## 当前行为

- 复用 `public/models/welcome-terminal-v1.glb` 的原始几何、彩色 PBR 材质、屏幕图案和 `TerminalUnfold` 动画；没有生成新的网页模型或灰色替代材质。
- `src/resident-terminal.js` 管理终端资源及桌面落点。终端飞行、缩放、转向连续，进入播放期间始终可见，尺寸不小于最终桌面尺寸；落位后保留同一个模型实例。
- 原 `folding_drawing_terminal` 逻辑根及其位置、旋转、比例保留；其子模型换为欢迎终端。新 `terminal_lid`、`terminal_dial`、`terminal_rail` 仍可独立识别与交互。
- 桌面落点根据真实桌面三角形测量，终端底部保留约 `0.003` 世界单位接触间隙，修正原资产包围范围继承的下沉。
- 房间其余 **35 个资产**分别使用独立动作配置、速度和错峰时间。配置库保留 36 项；终端由停靠控制器独占驱动，避免再次接收通用展开变换。
- 完成、跳过与减少动态效果均恢复确定的最终状态。原有房间根变换保持不变，永久终端恢复其精确桌面姿态；所有资源由各自所有者释放。

## 加速后的实际时间

欢迎与进入时间线均以 **1.25 倍速**播放。调试用 `introAt` 和时间线时间仍表示未乘播放速度的时间。

| 阶段 | 时间线秒数 | 实际播放秒数 |
| --- | ---: | ---: |
| 欢迎页出现完毕 | 2.10 | 1.68 |
| 首次进入至完整恢复交互 | 5.7016622 | 4.56132976 |
| 终端停靠结束 | 约 3.823 | 约 3.058 |
| 天空渐显 | 1.60–3.95 | 1.28–3.16 |
| 外景与灯晕渐显 | 1.90–4.10 | 1.52–3.28 |
| 室外接触阴影渐显 | 2.90–4.40 | 2.32–3.52 |
| 室内烘焙阴影渐显时长 | 0.95 | 0.76 |

GSAP 对极接近端点的进度有舍入，120 Hz 播放时钟采样在约 3.05 秒记录到已停靠。室内烘焙阴影仍等全部 36 项进度精确到位后才出现；外部接触阴影、天空和灯晕分别渐显，未恢复提前出现的多余物件阴影。
