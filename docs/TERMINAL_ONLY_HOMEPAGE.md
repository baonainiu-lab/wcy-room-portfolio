# 终端机首页恢复记录

2026-09-26 用户反馈人物模糊、动作切换过快，并授权「如果实在达不到标准就删除人物只保留终端机」。

原动图每帧 480×640，其中人物约 360 像素高。扩大构图后超出了该素材的清晰度。新一轮 image_gen 补绘提高了人物细节分辨率，但部分表情未按原姿态回收、不同帧的细节与轮廓仍不稳定。高清草稿未接入网站；据此采用用户授权的终端机方案。

此次恢复先使用已有 Blender 真实 3D 终端机和留白背景。后续按用户要求完成 V2 终端模型、大幅展示构图和日光背景，当前版本见 `docs/TERMINAL_SHOWCASE_V2.md`。下滑、点击箭头或键盘进入后，沿用终端移动、房间展开和终端落桌的原有动画。人物 HTML 层、入口模块和样式导入、加载等待及人物交接时间线均已从运行入口移除，因此不再请求人物图集或人物背景。隐藏的右上导航、音乐和复位控制、新标志均保留。

旧人物源文件、GIF、未引用的控制器和高清补绘草稿保留作离线制作记录，不代表已通过验收或已接入首页。动图曾调整到每帧 180/170/180 ms、动作间停留 2.8 秒，该节奏现仅存在于未启用的历史控制器中。

验证：生产构建通过；真实房间开场检查 16/16，常驻终端检查 5/5。浏览器实际下滑后进入完成一次，镜头控制恢复，错误列表为空；欢迎页只显示真实终端机。只做本地修改，未发布或部署。
