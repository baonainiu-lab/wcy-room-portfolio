# 小资产入场 V5

后续开场衔接和光影节奏已在 [V6](ENTRY_FLOW_V6.md) 调整；本页记录的小资产动作继续沿用，当前完整时间线与浏览器验证以 V6 为准。

2026-09-25。在既有 Blender 模型上设计六类更明显的动作，保留 V4 支点、设备零件绑定、承载顺序和防穿模限制。本轮只更改运行时动画，不新建或替换模型、贴图、个人内容和 UI。

| 新动作 | 使用物件 | 行为 |
| --- | --- | --- |
| 旋转落位 | 莫比乌斯雕塑、环形音箱、阅读微光灯 | 顺/逆向旋转，在物件已经长大时继续转动，最后准确回到原角度 |
| 轻跳落位 | 保温杯、机器人 | 正向抬起、落下，配合轻微转向与落地压缩 |
| 弧线缓降 | 几何标本罩、玻璃微景观、微型探测艇 | 缓缓下降，同时有受限的横向弧线与转向 |
| 翻起归位 | 折叠创作终端、折叠通讯器、相机 | 带倾角出现，再翻回原始姿态 |
| 侧滑归位 | 参考书、能量胶囊架、投影仪 | 从一侧滑向停放位置，带小幅转向 |
| 弹性舒展 | 笔座、耳机架、桌边暖光灯 | 先舒展高度，再打开宽度，轻微摆动收尾 |

机械花与水培盆还增加了更明确的旋开动作。新六类共用于 17 个独立物件。大件原有节奏继续保留。旋转不再在物件几乎不可见时提前结束；实际半程旋转残量为 68.7–98.8 度，翻起类为 15.1–25.2 度。桌面小件继续等待桌面稳定，并将各自间隔拉开。单件新动作约 0.84–1.08 秒，完整进入段约 5.232 秒。

## 验证

- 新动作实测 9/9：使用真实 GLTF 顶点与实际生产 GSAP 时间线，在 35%、50%、65% 阶段检查真实角度、支撑间隙、位置路径和缩放差异；另检查六类动作半程跳过以及减少动态效果的准确恢复。
- 原交互与展开 16/16、开场控制器 15/15、几何及资源恢复 3/3 均通过。
- 真实顶点包围范围检查、支撑面检查未检测到新增越界；145 个交接帧的三角边抽样没有交叉。抽样不等于整个场景所有三角的穷举证明。
- 生产构建通过，保留原有大包体提示。没有新增纹理、材质、网格或绘制调用，没有新增逐帧资源分配。未重新测量 120 FPS。
