# V7 首页动态

延续已通过的 B「日光画册」：米白纸面、寒蝉圆黑体 Heavy 立体标题、真实房间作为主视觉。用户本次要求首页房间可旋转，同时增加整体动效。

## 首页画面与交互

- 首页 `.entry-art` 接受指针输入，实时房间由 WebGL 渲染。CSS 不对房间画布或展示容器做假三维旋转、平移和缩放，保证拖动坐标与实际画面一致。
- 页面加载时保留 `room-day-v14.png` 作为静态占位；实时画面准备完成后，`.is-live` 用 0.42 秒淡入画布并隐藏占位图。
- `.entry-art` 内的 `.entry-live-canvas` 使用绝对定位覆盖展示区域，覆盖原画布的全屏固定定位；`touch-action: pan-y !important` 仅在首页覆盖 OrbitControls 的内联设置，允许窄屏纵向滚动。进入房间后的画布布局与触控仍由原全屏样式管理。
- 实时画面下方显示小型「拖动转动」提示。进入可交互状态后，双向箭头只提示三轮；拖动时提示减淡，光晕式落地阴影稍收紧，光标切换为抓取状态。
- 真实场景的旋转、指针拖动、渲染器复用、进入完整房间时的恢复由独立实时首页模块及 `main.js` 管理。

## 排版与纸面动效

| 元素 | 动作 | 时序 |
| --- | --- | --- |
| 「创作」「空间」 | 从下方 28px、轻微角度错落进入 | 1.05 秒，延迟 0.08 / 0.21 秒 |
| 大标题悬停 | 两组字分别抬起 4px / 7px，略变暖 | 0.55 秒过渡 |
| 页眉、侧注、页脚 | 轻微上移淡入 | 0.75–0.8 秒 |
| 页眉和页脚细线 | 从相应端展开 | 0.95–1.15 秒 |
| 说明、进度、入口、帮助文案 | 按阅读顺序错落出现 | 0.4–0.76 秒延迟 |
| 纸面暖光 | 单层渐变以位移和透明度缓慢移动 | 20 秒交替，不使用模糊滤镜 |
| 已就绪的进度圆点 | 小幅呼吸 | 3.6 秒周期 |
| 已就绪入口按钮 | 短暂掠过的金属反光 | 每 8 秒一次，悬停使用原即时反光 |

所有 CSS 循环在首页 `[hidden]` 或正在退出时暂停。`prefers-reduced-motion: reduce` 关闭纸面移动与呼吸，去除标题悬停位移，并将所有 CSS 动画限制为一次，避免极短循环。原房间导航、面板及控制条的 V5 动效保持。

## 涉及文件与验证

- `index.html`：增加装饰性拖动提示，不添加个人信息或新素材。
- `src/style.scss`：实时画布布局、占位交接、排版和纸面动效、窄屏及减少动态适配。
- Sass 编译验证通过，输出 CSS 41,558 字符（本次样式修改后）。
- 整体构建、浏览器桌面/窄屏、真实旋转及进入房间流程由主任务联合验证；此记录不把仅 CSS 编译视为完整浏览器通过，也不宣称稳定 120 FPS。

不修改旧网站、不上传或部署，未引入外部素材和依赖。
