# 房间 V15：近景纹理与动态表面

本轮依据用户要求检查房间小资产贴图、重新烘焙、修复近景穿模，并让电脑与窗景动起来。仅在独立项目本地接入。

## 贴图检查

V14 原始小资产 A2 图集的有效 UV 面积约 5.3%。V15 按资产用途重新分配 UV：A2 保留主屏外壳、计算核心、机器人；A9 承载桌面高频细节；A10 承载终端、档案、手记与植物。新图集均为 4096 方图，来自原程序材质的真实 Cycles 烘焙，没有放大旧 PNG。

- A2 有效 UV 面积 63.8%，被重新分配资产的线性纹理密度提高约 5.1–5.6 倍。
- A9 有效 UV 面积 43.2%，桌面资产提高约 7.4–7.8 倍。
- A10 有效 UV 面积 28.1%，相应资产提高约 3.4–3.8 倍。
- 新烘焙使用 96 samples；原 V14 文件保留。独立对象和交互标识继续保留。

具体 UV 面积、每对象 texel 密度与图集归属见 `assets/blender/texture-precision-v15-prepare.json`。最终日夜烘焙、几何修复及导出状态以 `assets/blender/dual-lighting-v15-export-report.json` 为准。

## 工作椅近景补修

浏览器近景验收发现白色工作椅背壳的断续灰线。源模型是连续陶瓷壳，这些线并非黑色软包的缝线设计。旧网页模型将整椅从 48,652 面简化为 8,000 面，白壳从 10,208 面简化为 1,652 面；共享 A1 中白壳仅约 223 texels/m，并有 232 条内部 UV 断边。

V15 恢复整椅原曲面，追加 A11 / 3072² 独立日夜图集。白壳正反两面使用连续参数 UV，厚度边单独展开，面内 UV 断边为零；白壳提高到约 966 texels/m。根对象、转轴、动画与交互保持。最终房间为 12 组图集、413,855 个三角形；其他对象几何与 UV 哈希验证不变。修复前中间源存于 `assets/blender/v15-pre-chair/`，详细数据见 `assets/blender/work-chair-v15-refinement.json`。

## 穿模修复

窗框、内侧灯线与窗景右侧原本侵入陈列塔。窗口整体右缘收窄 0.25 场景单位，左缘保持；最外窗框与塔框间留 0.025 间距。源模型与网页准备场景同步修改。六组窗框/窗景与塔框/背板配对的 BVH 检查从实际交叉变为零交叉，见 `assets/blender/window-clearance-v15-repair.json`。

网页近景增加局部三角形 BVH 扫掠保护。保护球覆盖相机近裁面四角，遇到表面沿表面滑动；仍保留原来的最小缩放距离与镜头控制。不会把整间房的包围盒当成实体，窗洞、椅子空隙仍可查看。首页、模态框、重置镜头、跨场景转场期间禁用并同步镜头姿态。

自由小物保持较大的悬停放大响应，放大时抬升底部，避免沉入桌面。位置与缩放使用同一条无超调曲线；装配在机构上的镜头、旋钮、铰链、花瓣等限制为 1.12 倍，保留独立互动。

几何回归：`scripts/check-room-camera-guard.mjs`；支撑面回归：`scripts/test-room-hover-clearance.mjs`。

## 动态屏幕与窗景

主屏以 5.8 秒停留、1.35 秒交叉淡入轮播三幅本项目图像：原创橙蓝雕塑、长廊日景、长廊夜景。均是原有真实 Blender 场景画面，个人作品资料仍待补充。屏幕保持点击进入作品长廊的交互。

窗外城市的日夜两图由原 ENV_CITY 实模重新渲染至 3072×1344；原主屏雕塑由 SCREEN_ART 重新渲染至 2880×1200，均保留构图而非插值。窗外图像增加云雾、双向交通光点和受限视差；窗口边缘固定，避免位移露边。现有日夜烘焙材质继续有效。这是图像表面的分层动态，不宣称整座城市已成为实时三维场景。

上述效果共用现有渲染器和网格，无新增 draw call。离开房间、隐藏页面时暂停；系统要求减少动态时保持静态。两幅额外屏幕图使用 KTX2，来源和文件校验见 `public/textures/live-room/SOURCE.json`。

## 本地验证

最终 12 图集版本已在浏览器检查白天 / 夜晚的椅背近景，原灰色 UV 断线消失；屏幕三幅轮播、窗景动态、日夜切换和长廊往返正常。14 张室内压缩贴图实际使用 ASTC，13 张日间贴图就绪。390×844 的布局检查在最后的椅子几何替换之前完成，页面布局未再修改。

资产校验通过：27 张贴图、95 个独立 ID，V14 原件未变。最终几何通过 12 项相机保护检查和 6 项真实 OrbitControls 闭环（5,780 帧）；松手后位置稳定，没有持续碰撞修正。自由小物支撑面回归通过。源报告见 `docs/validation/`。

最终浏览器采样在 Blender 烘焙停止、单个预览标签页下进行，844×795 / DPR 2，日夜近景各约 20 秒。GPU 单帧中位数 1.77–2.08 ms，P95 2.35–2.78 ms；RAF 帧间隔 P95 9.8–10.3 ms，中位回调速率约 120.48 Hz。由于部分帧间隔超过 8.33 ms，仍不宣称稳定呈现 120 FPS。完整数据：`renders/room-v15/performance-final.json`。

最终浏览器加载后的警告及错误记录为空；画面证据为 `renders/room-v15-final-chair-closeup.png` 与 `renders/room-v15-final-night-closeup.png`。旧的 `room-v15-closeup.png` 保留作为椅背修复前证据，不能视为最终版本。用户视觉验收待反馈，仅本地预览。

最终生产构建通过（36 模块）；保留 Vite 体积较大分包提示，未发生构建错误。
