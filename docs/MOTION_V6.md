# V6 房间机械运动

用户本轮要求“房间内多加点会动的元素，比如椅子转动”，首页另出三张概念，用户随后选择 B「日光画册」并进入实现。本轮运动直接在本地网站接入；V14 模型文件与选定字体保持。

## 已实现

`src/scene-motion.js` 由 6 个自动运动组件扩展为 12 个，复用主渲染循环与现有独立轴心，不加几何、贴图、定时器或新的渲染通道。`motion.revision` 为 6，合并获批首页后 `uiRevision` 为 6。

| 独立组件 | 自动动作 |
| --- | --- |
| `furniture.work_chair` | 左右各 20° 的明显转动，转到两侧停留后回正；20 秒一轮，回正后有约 7.6 秒完全静止 |
| `flower_petal_0/1/2` | 三片花瓣沿实际 Z 铰轴依次展开约 10.3°、停留并收起，相邻错开 0.42 秒 |
| `speaker_gimbal` | 环形音箱缓慢左右摆动约 6.3°，转动与停顿交替 |
| `v5_scout_drone` | 保留沿世界竖直方向 3.5 cm 上限的轻浮，6 秒周期 |
| `v5_clock_dial` | 轨道指针沿 Z 轴每 10 秒索引 30°，每次动作约 0.85 秒后停留；这是陈列机械动作，不代表当前时间 |
| `v5_projector_lens` | 镜头沿自身 Z 轴调焦约 13.8°，同时最多伸出 1 cm 后回位 |
| `v5_data_panel_selector` | 面板旋钮沿自身 Z 轴转动 30°，停留后回位 |
| `original_trefoil_geometry` | 玻璃罩内雕塑绕父级竖直轴左右转动约 27.5°，保持原有倾斜姿态与支座位置 |
| `v5_floor_lamp_head` | 落地灯头沿 X 轴缓慢俯仰约 5.7° 后回位 |
| `communicator_panel_1` | 通讯器上盖沿原 X 铰轴略微打开约 9.2° 后回位 |

机械动作使用包含停留段的五次平滑插值，并错开起始时间；只有无人机保持持续轻浮。已经回到静止目标的标量变换停止写入，避免末端微颤。雕塑重用预分配四元数，围绕展座竖直轴转动；无人机所有局部坐标使用同一插值比例，保证经旋转父节点后仍沿世界竖直方向移动。

## 真实模型轴与范围

检查对象为当前加载的 `public/models/orbital-atelier-v14.glb`，包含 95 个独立资产 ID（其中 2 个为外景）。

- 机械花源 Blender 铰轴为 Y，导出 GLB 后为 Z；自动花瓣动作已修正为 Z。主线程同时修正 `src/main.js` 中花瓣点击展开/复位的两个 tween 为 Z。
- 时钟、投影镜头、面板旋钮的实际 GLB 顶点面向局部 XY 平面，轴向厚度分别约 3.05、5.90、3.90 cm，旋转轴确认为 Z。
- 椅子以真实 GLB 顶点计算脚印凸包，在 −20° 至 +20° 每 1° 检查一次；41 个姿态均与工作台保持分离，最小分离轴间隔约 **0.4405 m**。这是椅子和工作台的离散几何范围验证，不能替代整个房间的连续碰撞检测。
- 雕塑顶点对照玻璃罩旋转体内轮廓的最小径向余量约 **0.03188 m**；绕父级竖直轴运动时，顶点高度与半径保持不变。
- 镜头轴向行程测得 **0.01 m**，X/Y 位置不变。时钟、旋钮、雕塑、灯头、通讯器轴心位置不变。

## 交互优先与减少动态效果

保留 V5 的悬停父子关系排除、点击 hold、弹窗/拖动/复位停表、`prefers-reduced-motion` 零自动变换写入、delta 0–0.05 秒夹紧。GSAP 对 rotation、position 或 quaternion 的 tween 均优先于自动运动。索引指针恢复时取最短角度，避免长时间悬停后追赶多圈。

## 已执行验证

- `node scripts/check-scene-motion.mjs`：**12 项通过**。除上述真实模型范围，覆盖 12 组件运动、其它资产/层级/scale 不变、竖直轻浮、减少动态效果零写入、禁用停表、悬停让权、点击 hold、真实 GSAP tween 让权、长 delta 恢复、椅子明显转动与真实停顿。
- 椅子实测区间 −20° 至 +20°，最大角速度约 **0.39718 rad/s**，最长完全静止段约 **7.6417 s**。
- `node scripts/check-room-entry.mjs`：**4 项通过**。V14 的 37 个房间根资产、3 个静态网格、2 个外景根资产及 32 个错峰入场物件均保持，完成后原始局部/世界变换恢复。

以上验证使用真实 Three.js、GSAP 和 GLB 顶点，不产生 WebGL，也不构成帧率或网页观感结论；浏览器验收与构建由主线程继续完成。
