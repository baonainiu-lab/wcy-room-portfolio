## 网站接入（2026-09-24 已完成）

用户“继续吧”已批准渲染并授权接入。prepare、Cycles 日夜各四组烘焙、GLB 导出、KTX2 压缩均已实际完成。

- 正式网页模型 `public/models/works-gallery-v1-compressed.glb`，35,883,624 bytes，160 节点、89 网格 / primitives、86 个资产 ID、785522 三角形。
- 内嵌四张夜间 KTX2，外置 `public/textures/works-gallery-v1/day-{0..3}.ktx2`；4096 / 3072 / 4096 / 4096，保留 mip 链。源 PNG 与原 GLB 保留。
- 原模型与压缩模型的 255 个非图片 bufferView 字节完全一致，节点、层级、材质和几何 JSON 一致。当前浏览器实际使用 ASTC 4×4（格式 37808）；双状态纹理有效载荷估算 608 MiB → 152 MiB。压缩主要节约显存，传输体积不是减少：原 GLB 33.91 MB → 35.88 MB。
- 顶部“作品”、房间主屏和主屏提示统一进入长廊。约 2.07 秒镜头移动，以屏幕前的金属门框擦镜遮住场景交接，随后放缓展开长廊。此为设计性遮挡过渡，不是两座完整建筑间可自由步行的连续空间。
- 同一个渲染器每帧只绘制当前场景。长廊预加载并完成材质编译后才开始过渡；载入失败可重试或留在房间；取消请求的过期结果不再触发转场。
- 返回恢复房间原镜头与目标，日夜与声音设置延续。宽高比变化时重新适配构图。六个展位按钮逐一验证，项目资料均待补充。
- 画册翻动、独立抽屉滑动、雕塑和小部件的点击响应已绑定；代表性画册和抽屉通过真实光线拾取。透明柜壳不会阻断物件拾取。
- 修正模板控制器的平移边界，使长廊两端展位可以居中；原房间默认边界不变。统一取消镜头 timeline，避免旧完成回调与缩放窗口/转场竞争；弹窗打开时 resize 保持背景 inert。

浏览器验收：844×795 默认预览、390×844 弹窗缩放、320×740 窄屏无横向溢出，所有可见按钮留在视口内。六个作品面板、主屏提示入口、日夜端点、原镜头恢复、代表小资产点击通过，最终控制台无报错。构建通过（33 模块）；仍有单 JS chunk 大于 500 kB 的 Vite 建议警告。

性能文件位于 `renders/works-gallery-v1/web-performance-*.json`：结束 Blender 烘焙、仅保留一个预览标签，在 844×795 / DPR2 下采样，日夜均为 91 draw calls（含背景）。日景 GPU P95 5.55 ms，夜景 5.67 ms；日夜 RAF P50 8.3 ms、P95 9.2 ms。测量中的 RAF 中位数约 119–120 FPS，但存在慢帧，不宣称全程稳定 120 FPS；RAF 与 GPU timer 也不等于操作系统实际呈现帧率。源码与浏览器测试的具体边界见 `web-verification.json`。未对所有 86 组件逐个点击，也未做减少动态效果的设备模拟。
