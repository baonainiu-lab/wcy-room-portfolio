# 入场穿模修复 V4

> 防穿模机制继续保留；2026-09-25 后续的小物件动作扩展见 [小资产入场 V5](PROP_ENTRY_V5.md)。本文是修复当时的检查记录。

2026-09-25。保留彩色 Blender 终端与首次下滑展开房间的编排，只修正中间姿态与零件绑定。本地项目预览，不部署。

## 修复

- 显示器的银框、支臂和机箱圆盘、螺栓原本留在静态 A0 网格。按 Blender MCP 核验的原三角区间，将现有零件绑定到各自设备根节点。原 GLB、贴图、法线、UV 没有重导或重烘焙。新增两个绘制网格，三角总数不变，93 个房间组件和 37 个交互根保留。
- 所有物件用当前旋转参与支点补偿，取消从支撑面下方向上穿出的位移；基于原始顶点边界限制展开范围。椅子的大角度旋转在尺寸较小时完成。桌面和茶几上的小物会等待承载家具展开稳定。
- 外景保持最终位置与尺寸，通过独立临时材质从背景色显现，保留深度遮挡。环带不再从中心扫过房间；完成或跳过后恢复原材质。
- 终端按实际 Blender 墙体构件、地板与家具的包围范围计算净空，从房间中央上方缩回，避免屏幕、盖板或底壳切入正在生长的房间。
- 干净开场烘焙继续生效。所有物件到位后恢复正常光影。完成与跳过都精确恢复原位置、旋转和比例。
