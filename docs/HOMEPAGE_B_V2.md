# 首页 B：日光画册

**V7 更新：** 当前主视觉已改为可自动 / 拖动旋转的真实三维房间，以下 V6 静态实现记录作为历史保留。原 PNG 仅作载入占位。当前行为与验证见 [实时房间 V7](HOMEPAGE_ROOM_V7.md) 和 [动效 V7](HOMEPAGE_MOTION_V7.md)。

用户验收选择：**“B 日光画册：明亮米白＋大标题”**。

对应已选概念图：`docs/concepts/homepage-v2/b-day-editorial.png`。本次以真实 HTML、CSS 和当前房间渲染实现首页，概念图本身不作为网页背景。

## 页面设计

- 暖米白纸面、斜向日光和细分隔线，顶部保留“创作空间 / 个人作品集”身份。
- 单行大标题使用现有 `Atelier Rounded Display` 字体（寒蝉圆黑体 Heavy 的已许可本地子集），900 字重配石墨灰多层立体厚度；不新增第三方字体。
- 桌面以左侧入口和右侧完整房间构图；小屏改为标题、房间、入口依次排列。房间图始终 `object-fit: contain`，不裁切墙顶或底座。
- “个人资料与作品待补充”保留。首页不加入尚不可用的作品或个人导航，也未编造个人经历。
- 入口标题和房间图片各运行一次短时出现动效；按钮保留悬停、按下及反光反馈；减少动态效果偏好继续生效。

## 与加载及退出动画的衔接

`index.html` 保留 `.loading-screen`、`.loading-content`、`.loading-top`、`.loading-bottom`、`#loading-title`、`.loading-progress`、`.loading-meter`、`#loading-status`、`.loading-screen-button`、`.no-sound-button`、双 `.entry-shutter` 和 `.entry-reveal-line`。

`.entry-art` 位于 `.loading-content` 内，因此随现有 GSAP 内容退场一起淡出。双幕改为同一幅连续纸面背景的左右两半，退出仍使用原左右展开方式。双幕固定于视口，确保短屏滚动时背景完整。页面自身可纵向滚动，短屏不会将入口按钮裁掉。

载入进度、失败重试、静音选择、进入后房间整体生长、键盘焦点和日夜控制仍由 `src/main.js` 原逻辑管理。根任务已将进入时的场景初始灯光设为白天，使其与首页日光画册一致。
