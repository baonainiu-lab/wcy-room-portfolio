# 方案 C：光核策展人 / Lumen Curator

这是用于比较与验收的独立角色候选，尚未放入作品集网站。

`front.png` 与 `back.png` 是本目录内真实 Blender 模型的 1200 × 1500 摄影棚渲染。造型、衣甲、轨道环、眼睛、发光核心、手指和腰包均由几何体构成，没有把 AI 效果图贴在模型表面。

## 角色语言

- 石墨色圆角楔形头，嵌入琥珀面罩、细白双眼与温和微笑。
- 头后偏轴轨道环由真实管状结构构成，以白色长弧与暖光短弧区分方向。
- 非对称象牙白包裹背心、开放 C 形领与少量香槟金接缝，形成策展人式的克制着装。
- 开放腹部展示暖光核心，呼应收集、整理与呈现创作的概念。
- 肘部、前臂双杆、手指、膝关节均有分段结构；橙色三槽腰包可作为未来作品分类入口。
- 约四头身，宽象牙白靴稳定重心，保留艺术玩具感。

## 文件

| 文件 | 用途 |
| --- | --- |
| `build.py` | 可复现的建模、材质、导出和渲染脚本 |
| `option-c.blend` | 可编辑模型与摄影棚场景，打开时是正面三分之四镜头 |
| `option-c.glb` | 只包含角色几何及材质，不含摄影棚灯光、地面和相机 |
| `front.png` | 正面三分之四实模渲染 |
| `back.png` | 背面三分之四实模渲染 |
| `manifest.json` | 几何、文件与材质统计 |

## 重建

在本目录执行：

```sh
/Applications/Blender.app/Contents/MacOS/Blender --background --python build.py
```

脚本只向自身所在目录写入文件。正背面图片、Blender 文件与 GLB 来自同一套几何，修改脚本即可重建全部输出。浏览器、Blender 的灯光和色彩管理不同，因此不能保证不同渲染器像素完全一致。

头部、身体、双臂已经分为独立父级，双眼为独立网格；当前没有蒙皮绑定或动作片段。验收造型后可以继续加入眨眼、转头、挥手和腰包作品入口。
