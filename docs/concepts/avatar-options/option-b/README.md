# B · 月相领航员 / Moonphase Navigator

**仅供人物外观验收。未接入网站。**

它是一位安静、专注的探索型创作者。用一个连续的月牙兜帽作为识别符号；轮廓从宽大的头部收向领口，再展开成偏斜的结构披风，最后落在窄裤和厚底靴上。珍珠白、深青、石墨灰和柿橙组成克制的四色层次。

设计保留三处视觉重点：月牙兜帽、平静的横向面罩、圆形制图镜。披风正面斜折线与橙色下摆表达服装结构；肩部短月弧和背部三枚细缝让侧面与背面也成立。

## 文件

- `hero.png`：真实 Blender 模型的 1200 × 1500 三分之四视角渲染。
- `front.png` / `back.png`：同一模型的正面与背面渲染。
- `moonphase-navigator.blend`：可编辑模型、材质与棚拍场景。
- `moonphase-navigator.glb`：仅角色的静态模型导出，不含棚拍地面、相机、灯光。
- `build_lunar.py`：完整的确定性建模、导出、渲染脚本。

模型包围盒尺寸为高 2.657、宽 1.231、深 0.749 个 Blender 单位。GLB 为 59,552 个三角形、55 个网格、8 种材质、约 1.24 MiB。此版本优先用于外观验收，尚未骨骼绑定或制作动画。

## 可还原的范围

验收图就是这份三维模型直接渲染的结果，并非先生成一张概念图再猜测它的三维结构。脚本可重新生成同一模型；GLB 与 Blender 文件来自同一份几何和材质。不同渲染器、色彩管理、灯光和屏幕仍会影响最终像素，不能把几何一致等同于网页截图像素完全相同。

将来可交互的部位：头部轻转、眼睑变化、圆形制图镜的作品入口、肩臂抬起。需要验收后另做绑定与动作阶段。

复现命令：

```sh
/Applications/Blender.app/Contents/MacOS/Blender --background --python build_lunar.py
```
