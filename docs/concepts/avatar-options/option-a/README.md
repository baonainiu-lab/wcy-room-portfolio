# 方案 A：折线造物师

**状态：仅供外观选择，尚未通过用户审批，未接入网站。**

这是一位约 3.5 头身的成人创作者艺术玩具。设计以“折线”为识别语法：大块侧分雕塑发束、左右不对称的高折领、宽斜挎带、折叠本和鞋面斜向包边互相呼应。角色气质是提出的设计方向，不代表已经确认的用户长相、穿着或性格。

## 造型理由

- **头部剪影**：黑色大块侧分发束形成清楚的斜向重心；圆润收颌、嵌入式椭圆眼、轻挑眉与克制的微笑，避免方块机器人与无表情人台。
- **服装剪影**：奶油色短夹克扩大肩部，折领建立层次；气球裤在脚踝收口，厚底靴稳定重心。局部夸张集中在衣服剪裁和发型。
- **配色材质**：奶油陶瓷感服装、石墨针织内层、陶土色皮革工具袋、暖米肤色与低调浅黄铜。没有皮肤毛孔或写实毛发，保持可重复制作的雕塑语法。
- **功能物件**：宽背带连接侧腰工具袋；手持折叠本和细长创作笔；三瓣徽记作为小尺度识别点，没有堆砌与创作无关的装饰。

## 可选交互方向

外观通过后，可以制作眼神跟随、眨眼、轻点头和手持本展开；点击本子进入作品，点击徽记查看简介。这里仅描述交互潜力，没有编写交互功能或接入网站。

## 文件

- `option-a-front-threequarter.png`：正面三分之四，1200 × 1500。
- `option-a-back-threequarter.png`：背侧三分之四，1200 × 1500。
- `option-a-fold-creator.blend`：完整可编辑模型和摄影棚。
- `option-a-fold-creator.glb`：为后续技术评估保存的模型，仍位于审批目录。
- `build_option_a.py`：可重复生成模型、导出与渲染的 Blender 脚本。

渲染直接来自实际模型，没有使用 ImageGen 概念图。外观选定后可以复用同一几何资产；不同渲染器、灯光和相机仍会改变最终画面的像素表现。

重建命令，在项目根目录运行：

```sh
/Applications/Blender.app/Contents/MacOS/Blender --background --python docs/concepts/avatar-options/option-a/build_option_a.py
```

后台进程建立独立新场景，所有生成文件都写入当前方案目录；不修改房间、public、src 或网站页面。
