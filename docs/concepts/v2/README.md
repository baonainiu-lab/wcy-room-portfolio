## 设计方向

- 空间：连续曲面金属框架包裹工作区和远景窗口；悬挑桌面与独立展示壁龛形成主次，前景保留可浏览的空地。
- 造型：大体块用圆角曲面与非对称切线，小资产用可辨识的支撑、铰链、嵌套结构和材质连接。
- 材质：冷银色拉丝钛金属、深石墨、乳白陶瓷、烟色玻璃；橙色软包座椅形成主要暖色焦点。
- 灯光：中性柔光与少量冷光刻画结构，壁龛保留暖白照明，小物仅在状态点使用琥珀色。

## 小资产的拟定交互

下列行为只为概念提案，并未实现；内容用途也未代用户确定。

| 物件 | 结构特点 | 可独立实现的交互方向 |
| --- | --- | --- |
| 三足陪伴机器人 | 陶瓷卵石状机身、横向传感带、钛金属关节 | 转向、轻微俯仰、状态灯回应 |
| 折叠创作终端 | 不等宽双面玻璃、偏置铰链、支架与独立笔 | 轻微展开，打开待补充内容 |
| 档案匣 | C 形支架、三枚独立卡匣与导轨 | 逐枚抽出与归位，各自绑定内容 |
| 三瓣机械花 | 三片金属花瓣、短轴铰链与球形核心 | 逐瓣开合、内核转动 |
| 耳机 | 连续金属头梁、独立耳罩、薄支架 | 拿起/轻摆或静音切换 |
| 环形音箱 | 陶瓷环体、织物声学面、短底座 | 声音状态与轻微反馈 |

其他相机、键盘、杯子、植物、桌椅等仍需作为独立对象设计与导出，不因为未出现在细节图中而合并。
