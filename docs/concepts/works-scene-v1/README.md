## 选定后的实现边界

- 顶部「作品」、房间主屏 main_display 和主屏 callout 统一进入作品场景；其他小资产继续原有独立动画。
- 同步平滑移动相机和注视目标；建筑遮挡处允许隐藏场景替换，避免穿墙和硬切。时间在实际镜头与路径确定后再调，静态图不证明过渡平滑。
- 转场时暂停悬停、拖动与重复点击；新场景就绪后才开始过渡，加载失败则保留房间并支持重试。
- 返回房间恢复离开时的镜头；日夜与声音选择延续。减少动态效果时采用短淡入。
- 每个展位与小资产保持独立对象、稳定标识和合理旋转中心。后续通过 Blender 制作、材质贴图、灯光与渲染验收。
- 尽量保持同一渲染器，按阶段绘制当前场景，控制玻璃叠层和实时灯光。120 FPS 继续是实测目标，概念阶段不作达标承诺。
- 仅本地；不部署、不推送旧仓库、不修改旧项目。
