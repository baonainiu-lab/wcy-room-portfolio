# 轨道造物师 · 角色方案 V2

用户反馈 V1「设计不够丰富也不够贴合我的人物」，随后要求「继续制作」。未提供新增相貌或个人经历资料，因此本版依据已知的网站审美偏好继续设计，不宣称还原本人。

## 本版变化

- 将站立挥手改为正在使用折叠终端创作的动作，配合挑眉、侧头和半笑表情。
- 使用深石墨工坊夹克、乳白肩部拼接、橙色领口、卷袖、工具带和不同材质的功能连接件，建立更丰富的服装层次。
- 用三瓣机械花徽记呼应网站已有的机械花；折叠终端、三格档案匣与三足机器人同样取自现有网站物件体系。
- 增加专注、发现灵感、带一点怀疑的三种表情，以及服装背面与两组道具特写。

这些是原创角色设定，不代表用户真实外貌、性别、职业、经历或私人物品。
