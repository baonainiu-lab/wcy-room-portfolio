# 轨道创作者 · 人物概念 V1

根据用户请求「根据你对我的了解为我设计一个三维卡通人物形象，风格类似迪士尼人物风格，我会把这个形象加入到我的作品集网站中」制作。

## 设计依据

延续现有「轨道创作舱」的冷银、石墨、乳白与橙色点缀，以及圆角曲面和轻微不对称的造型。角色以亲和、好奇的未来创作者为设计方向；短发、服装、表情与道具均为创作设定，不代表已知的用户真实相貌、性别、职业或经历。

- 银白短夹克、石墨裤装、橙色内衬：与网站场景形成一致配色。
- 轨道胸针、弧形衣片：建立与创作舱的视觉联系。
- 创作板、自然挥手：适合作品集欢迎形象。
- 动画电影式眉眼、柔和皮肤与布料质感：兼顾亲切感与三维体积。
