# UI 概念 V1 实现记录

状态：用户明确授权“ui先按这个概念图设计吧”，随后要求“继续”。已按[批准概念](concepts/ui-v1/README.md)接入本地界面，最终 `pnpm build` 通过（20 个模块）；本轮指定视口与交互的浏览器 QA 已通过，本轮性能报告已保存。用户尚未最终验收实现的视觉。

## 已接入

- 顶部使用轨道线条标志、“创作空间 / 个人作品集”及“作品 / 关于 / 联系”文字导航。
- 底部为独立金属胶囊控制条，包含白天、夜晚、声音和镜头复位；保留拖动旋转、滚轮缩放的简短提示。
- 单个随场景物件定位的提示替代三个厚标牌。作品、关于、联系分别绑定现有主屏、机器人和通讯器实体；提示跟随物件投影，不额外新增三个场景牌体。
- 保留 37 个室内根资产、93 个室内 ID 及子部件独立交互。常规小物件的悬停和点击动作继续保留，入口物件打开对应内容面板。
- 加载页面、进入按钮和弹出面板使用配套样式，并加入移动端布局规则。个人姓名、项目和联系方式仍明确显示“待补充”。

## 静态审阅后的修复

- 打开面板时重置真正的 `.modal-wrapper` 滚动容器，避免不同面板继承上次滚动位置。
- 关闭面板时检查原焦点是否仍可见、可用；如果物件提示已经隐藏或禁用，回退到当前栏目对应的顶部导航按钮。
- 窗口宽度跨过 600 px 镜头布局边界时强制重新适配房间，避免只根据宽高比变化阈值而漏掉布局切换。

以上三项已写入代码。默认作品提示的 Enter / Esc 与焦点回退已经浏览器实测通过；面板滚动复位及跨 600 px 连续缩放的专项结果尚未单独记录。

## 本轮 UI 构建与性能

最终 `pnpm build` 通过，20 个模块；JavaScript 1,123.60 kB（gzip 345.60 kB），CSS 17.11 kB（gzip 4.31 kB），仅有常规 bundle 大小提示。

[UI V1 性能报告](../renders/performance-ui-v1.json)及[原始快照](../renders/performance-ui-v1-samples.json)记录本地 844×795 CSS 像素、DPR 2 的白天静置画面，45.14 秒 / 8 次快照。采样时无打开的面板或活跃悬停，交互另行检查。

| 指标 | 本轮实测 |
| --- | --- |
| 快照报告 FPS 的中位数 | 120.4819 |
| 帧间隔 P95 范围 | 9.8–10.1 ms |
| GPU P50 范围 | 2.669–2.955 ms |
| GPU P95 范围 | 4.495–5.361 ms |
| CPU P95 范围 | 1.1–1.2 ms |
| 绘制 / 渲染三角形 | 104 / 375,079 |
| 错误 / 稳定 120 验证 | `errors: []` / `stable120Verified: false` |

这是短时本地静置采样，未证明稳定 120 FPS，不能用接近 120 的中位数代替 8.33 ms 帧预算的持续验证。


## 范围

本轮修改界面与入口绑定，不改变 V12 Blender 模型、日夜烘焙资产与灯光状态；概念图生成的新背景建筑不在本轮实现范围。角色继续暂不接入。仅在独立项目本地预览，不修改旧项目、不上传仓库、不部署域名。

上述 QA 仅覆盖列明的视口与操作；加载过渡、所有物件及全部镜头角度未在本记录中作全面验证声明。

[预览检查](PREVIEW_CHECK.md)中的 V12 模型截图、交互及 42.07 秒静置性能样本发生在本轮 UI 接入前，应保留为模型阶段证据，不作为新 UI 的性能或完整验收结果。未宣称稳定 120 FPS。
