# 入场动效 V4

用户要求房间框架也逐渐放大，并重新设计首页进入房间的转场。本次只更改网页入场编排；仍使用 V13 场景和已选定的圆黑立体字体。

## 新的过程

- 点击进入后，首页文字在 0.38 秒内轻移并淡出。中央细光线展开，两块全高背景从 0.3 秒起向左右滑开，1.5 秒时首页完全收起。
- 从点击后的 0.42 秒起，整个房间由原尺寸的 4% 平稳放大到 100%，持续 1.95 秒。围绕房间底部中心缩放，墙体、窗户、平台及固定家具同步出现。
- 32 组小资产在房间开始放大后的 0.65 秒起错峰展开，间隔 0.034 秒；使用各自原比例，保留独立部件和旋转中心。最后一组在点击后 2.904 秒完成，再用 0.5 秒显现界面。
- 外部展廊、泊位、光晕及覆盖码头的接触阴影保持原位。动画不改模型、贴图、材质或灯光。

`src/room-entry.js` 动画整个房间场景根节点，因此覆盖原来不在资产列表里的两块静态墙窗 mesh。没有合并网格、递归缩放全部子部件，也没有按动画中的小尺寸重算相机或命中范围。最终恢复原始变换后才开启交互。主页转场使用 transform / opacity，房间使用现有 GSAP 数值动画，不增加渲染通道或循环视觉效果。

减少动画偏好下，房间直接恢复完整尺寸，首页短淡出；WebGL 中断时终止入场，恢复模型变换、幕板和首页文字，显示重新载入提示。

## 验证范围

- `node scripts/check-room-entry.mjs` 通过：包含旋转和非均匀父级的固定底部中心、未标记墙体、1.14 原比例、独立子组件、外景及阴影不变、恢复与 UI 回调顺序、中断恢复、减少动画路径。
- 同一检查读取实际 V13 GLB 层级：37 个房间根、2 个静态框架 mesh、2 个外景根；32 组错峰资产，组装时间 2.484 秒（另加 0.42 秒首页起始偏移）。所有局部与世界变换最终恢复。
- 浏览器 844×795：首页起态、收起后仍在放大的房间中段及完整终态已目视检查。点击真实主屏打开作品面板成功。
- 在框架放大期间把视口切换为 390×844，入场继续完成；页面宽度为 390，无横向溢出。控制台 warn / error 为空。
- `pnpm build` 通过，21 个模块；CSS 22.19 kB / gzip 5.50 kB；JavaScript 1,125.42 kB / gzip 346.15 kB。仍有既有的大文件提示。
