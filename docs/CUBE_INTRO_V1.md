# 立方体展开入场 V1

2026-09-25。本记录对应用户指定 Abigail Bloom 的 `firstIntro` / `secondIntro` 编排，以及随后追加的“每件小资产单独动作、按大小调整速度和时间差”“必须由方块展开出房间”。仅接入本独立项目的本地预览，未修改旧项目、推送仓库或部署域名。

本轮采用同一 Three.js 场景、相机和渲染器：小立方体欢迎页 → 首次进入手势 → 立方体扩大并以真实铰链打开 → 房间主体与各件资产展开 → 恢复既有导航和物件交互。欢迎方块由六个有厚度的真实网格面组成，展开至当前房间的实际包围盒尺寸；底面、后面、左面作为过渡外壳，与现有房间交叠后淡出。

当前自动检查 **13 / 13 通过**，详见 [检查报告](validation/cube-intro.json)。浏览器检查也已完成，详见 [浏览器记录](../renders/cube-intro-v1/web-verification.json)。最终视觉验收仍待用户反馈，不据此宣称稳定 120 FPS。

## 编排与状态

`prepared` 阶段先记录原始姿态，房间暂时隐藏。加载界面为不透明米白背景，避免模型与材质准备时闪现；模型、真实日夜贴图与着色器预热完成后才调用 `ready()`。

`welcome` 阶段背景覆盖层透明，米白由同一 3D 场景输出。方块约 0.7 秒弹性放大，约 0.5 秒时开始移动让出文字位置；欢迎文字从各字遮罩下方升起，最后淡入向下箭头。桌面方块偏左、文案偏右；宽度不大于 700 px 时方块位于上半区，文案居中置于下方。没有额外图片、视频或第二个渲染器代替该方块。

`playing` 阶段时间以首次进入触发为零点，各段有意交叠：

| 相对时间 | 当前实现 |
| --- | --- |
| 0 秒起 | 欢迎文字逐字退回遮罩，箭头淡出；进入只接受一次 |
| 0.1–1.75 秒 | 方块移动、旋转一整圈并扩大；相机平滑插值到根据当前视口计算的房间构图 |
| 1.05–2.65 秒 | 方块前面、右侧面、顶面围绕各自真实铰链翻开；底面、后面、左面保留为过渡外壳 |
| 1.6 秒起 | 现有房间从实际底部支点展开，主体约 1.3 秒到达原始比例 |
| 2.15–3.0 秒 | 已展开的临时方块外壳渐隐，与持续显现的现有房间衔接 |
| 2.3 秒起 | 姓名与身份文字逐字升起；仍使用“姓名待补充”“身份介绍待补充” |
| 2.5 秒起 | 墙面陈设、家具、桌面物件、设备、椅子分组交叠；组内各资产按独立偏移出现 |
| 3.2 秒起 | 原有环境、外部模型及接触阴影回归；烘焙材质暗部从临时提亮恢复至原图，减少空房间里预烘焙家具阴影的突兀感 |
| 约 5.9 秒 | 最后一件资产归位后身份与品牌淡出，释放临时方块并移除输入锁，恢复现有 UI 与交互 |

时间反映记录时的源码，结束时间由实际资产尺寸和最后一个动作计算。方块目标中心和三轴尺寸来自当前房间 `bounds`；窗口变化时重新计算终点构图与方块屏幕位置，保持已进行的进度。

## 36 件资产的独立动作

V15 保持 37 个室内逻辑根节点。`architecture.platform` 随房间主体展开，其余 **36 件**均在 `ROOM_ENTRY_MOTIONS` 中显式记录动作、组内延迟、节奏调整和收尾角度；不会把子组件合并或给多个层级重复缩放。

| 组别 | 件数 | 动作示例 |
| --- | --- | --- |
| 墙面陈设 | 7 | 档案坞侧滑、花瓣舒展、盆景落定、垂植物竖向展开、时钟转入、面板倾转、灯条横向铺开 |
| 主要家具 | 6 | 桌面与地毯铺开、躺椅落定、茶几与花盆升起、落地灯竖向展开 |
| 桌面小物 | 9 | 杯子落定、笔记本倾转、书籍侧滑、罩钟落定、雕塑旋转、盆栽舒展、笔座展开、胶囊架侧滑、阅读灯转入 |
| 设备 | 13 | 显示屏与终端倾转、主机升起、机器人与相机落定、耳机架竖向展开、音箱旋转、键盘铺开、投影仪侧滑、箱体升起 |
| 工作椅 | 1 | 独立放大与轻快旋转，最后恢复原始姿态 |

动作时长根据真实包围盒相对房间尺寸计算，再叠加每件资产的节奏值，限制在 0.42–1.12 秒；工作椅转动增加 0.18 秒收尾。当前真实 V15 测试中，大桌子约 **1.071 秒**，杯子约 **0.422 秒**。同一节奏修正值下，约 1.804 m 的机器人包围盒对角线对应 0.692 秒，约 0.672 m 的无人机展示件对应 0.594 秒，证明速度差同时受实际体量影响。

`spread`、`unfurl`、`bloom`、`panel` 使用不同三轴展开比例；`rise`、`settle` 与左右侧滑叠加短距离位移；转入和椅子动作使用独立角度。围绕原姿态旋转矩阵及其逆矩阵补偿展开支点；桌、地毯和键盘等固定支点动作在非均匀父变换下也保留原包围盒底部锚点。带落定、升起或侧滑的动作有意离开该锚点，结束时回到原位。

`restore()` 直接恢复原始 position、scale、Euler 顺序和原始 quaternion，并恢复可见状态。原 GLB 部分 float32 四元数并非数学上完全单位化，因此另外复制原始 quaternion，避免经 Euler 往返引入微小偏差。实际检查覆盖房间内 93 个 ID 与 2 个外部 ID，共 **95 个独立组件**、102 个网格、413,855 个三角形；GLB 几何与原始文件没有被动画改写。

## 输入、跳过、失败及减少动态效果

- 首次向下滚轮触发；向上、零增量和带 `ctrlKey` 的缩放滚轮不触发。
- 手机单指上滑超过 16 px 触发；多指、向下及取消的触摸不触发。真实触摸只走 touch 分支，忽略同时产生的 touch pointer，避免多指手势从 pointer 旁路误触发。
- 箭头使用原生 `button`，支持点击与键盘。背景 ArrowDown、PageDown、空格也可进入；按钮上的空格保留原生行为。
- `welcome → playing` 后同步关闭进入条件；重复事件不会重放或倒放。捕获阶段阻止滚轮、触摸移动和滚动键传到房间控件；`controls.enabled` 同时关闭，原有物件点击须等 `introComplete`。
- “跳过动画”及 Escape 在欢迎或播放时完成恢复。完成函数移除监听、恢复进入前的 `body.style.overflow`，随后由主入口恢复滚轮缩放、镜头拖动、物件点击和 UI 焦点。
- `prefers-reduced-motion: reduce` 下欢迎内容快速就位，触发进入即恢复完整房间，不执行长转场；播放期间偏好切换为减少动态效果也会立即完成恢复。
- 加载失败显示“房间载入失败，请重试。”与“重新载入”按钮；错误层为米白实底，进入和跳过按钮禁用。重试与资源释放仍由 `main.js` 管理。
