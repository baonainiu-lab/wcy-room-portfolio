# 长廊 V4 网页玻璃

展示架后方与顶棚的建筑玻璃使用 Blender V4 的独立 `GALLERY_ARCH_GLASS` 材质；展柜、灯笼和推车的玻璃仍保留各自的独立交互层级。网页实现位于 `src/gallery-glass.js`。

## 反射与透明

建筑玻璃使用实际长廊的日、夜两张局部反射全景图。着色器按相机视线和模型法线计算反射方向，用 Schlick Fresnel 混合反射与轻微青绿色透光。正视时可透视，斜视时反射增强；双界面近似保留玻璃的边缘反光。模型本身提供后片 32mm、顶片 30mm 的实际厚度及窗槽收边。

反射图以 sRGB KTX2 加载，GPU 解码后在线性空间混合。日夜比例直接共享长廊地面的主题 uniform，因此快速反向切换主题时不会出现独立动画错位。玻璃深度测试开启、深度写入关闭，使用闭合实体的正面法线；玻璃不参加物件拾取，避免遮挡作品和实体返回门框的操作。

这是局部静态反射探针，而非实时光线追踪或实时折射。反射方向随相机变化，反射图中的展品保持拍摄时姿态。采用盒投影近似改善近处框架反射的位置；无需额外反射相机、传输缓冲或完整场景绘制。

## 切镜与资源

每个建筑玻璃网格存储原生长廊坐标下的 `glassProbePosition`，而视线与法线使用当前相机和世界变换。当前转场只平移长廊，平移不会污染探针坐标。不同原生变换若复用同一几何体，会为该绑定单独复制几何；共同舞台的克隆仍共享绑定后的几何与材质。

长廊负责释放原模型材质及玻璃 shader，玻璃模块只负责两张反射贴图和自行创建的绑定几何。转场克隆借用这些资源，不能销毁它们。贴图加载失败会清理已完成的加载；绑定失败恢复原材质和几何，支持重新加载。

## 验证

运行 `scripts/check-gallery-glass.mjs` 检查绑定变换、共享资源、主题连续性及失败清理；同时运行 `scripts/check-gallery-transition.mjs` 检查共同舞台和重试路径。实际视觉、着色器编译、日夜切换及实体返回仍需在本地浏览器中验证；最终结果记录在 V4 验证文件中。该设计减少新增渲染负担，不等同于承诺所有设备稳定 120 FPS。
