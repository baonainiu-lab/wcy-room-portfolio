# Room V19：夜间墙光与实木地板

2026-10-01：完整资源已通过 CPU 验证并接入本地网站，当前为 Room19 / Gallery5 / Terminal3。实际浏览器已检查日景深木色、夜间墙光、开场恢复与三个场景切换。技术验证通过，不代表用户已作最终视觉验收；未部署。详见 `docs/validation/room-v19-main-browser.json`。

## 修改

- 新增独立的 `lighting.ceiling_warm` 顶灯。3000K 暖光包含下照、后墙上部与左墙三个方向，让夜景墙面保留木色与受光层次；白天关闭这组三盏照明。
- 删除地板的九条黑色实体线：九个 3mm 管状组件，共 90 个四边面 / 180 个三角形。保留其余模型的位置、法线、UV 与独立交互层级。
- 保留用户已通过的深色木材颜色，降低地板介质反射并提高粗糙度，削弱日光下泛白的高光。源参数：粗糙度 .64–.82、coat 0、IOR 1.46、specular level .26。
- 长廊使用用户原先通过的 Gallery V5 光照与玻璃反射；About 已通过的 38 个来源/资产文件保持哈希一致。

## 制作记录

完整 4K 光照烘焙多次超过文件定向 MCP 的固定 120 秒限制，缩小分组仍然超时。已向用户说明具体限制后，仅长时间烘焙改为离线 Blender CLI，继续使用同一份不可变 prepared 文件、原分辨率和 96 samples，没有用降采样或降低分辨率绕过。

夜景在设备确认支持后使用 GPU OIDN；HIGH、ACCURATE 及 RGB_ALBEDO_NORMAL 不变。每张图的执行记录区分 MCP 与 CLI，并记录仅切换去噪后端的事实。
