# 房间与长廊的连续三维切镜 V3

> 2026-09-25 已按用户要求加快并拉近落点构图，当前时长与验证见 [SCENE_TRANSITION_V4.md](SCENE_TRANSITION_V4.md)。下文 2.8 秒是 V3 历史节奏。

用户否定了屏幕窗口放大的切镜后，本版改为共同三维场景中的弧线移动。房间与长廊在切镜时使用共享几何和材质的独立变换副本，长廊放置在 `[34, -0.185, 1.5]`；原场景物件变换不被移动。镜头先拉开、沿外侧移动，再落到另一场景的观看位置。正常时长 2.8 秒，减少动态模式为 0.32 秒静态画面混合。

开头 18% 和末尾 24% 对共同舞台与原生场景作全画面渐变，两个相机对对应主体的投影保持一致；中段实际渲染共同三维舞台。没有窗口放大、光门边框或不透明金属遮挡。界面在切镜时轻淡出并禁用重复操作，结束后恢复。

长廊左侧实体入口 `gallery.architecture.portal` 支持悬停和点击返回。提示锚定到门廊，常驻独立返回按钮已移除；Esc 和加载失败时留在房间仍可用。六个展位与占位资料面板保持。

## 稳定性

纹理载入后预编译并实际离屏绘制，提前完成显存和渲染目标分配。双缓冲使用当前绘制分辨率，支持时采用半浮点颜色；中间通常为一次场景渲染加输出，首尾混合需要两个场景渲染。

开始移动前清空 OrbitControls 的旋转、平移、缩放残量并恢复可见相机姿态，避免清空阻尼产生跳动。结束时直接交接已经渲染的终点，不再二次拟合。隐藏页面暂停时间推进，单帧步长上限 50ms；窗口变化重新计算目标。预热失败清除克隆引用，重试不复用已释放模型。只释放自有缓冲与合成资源，不释放共享模型资源。

当前精简 V3 长廊保留薄底座，原生 ground Y=-0.88；共同舞台 offset Y=-0.185 对齐房间 ground Y=-1.065，底部净空约 0.025。两模型水平净距约 3.6733。此前城市大地台的坐标已废弃，见 [精简长廊 V3](WORKS_GALLERY_V3.md)。

- `renders/gallery-transition-v3/` 中早期浏览器数据使用带城市地台的 V2 模型，只作历史记录；不能代表当前精简 V3。

## 长廊环境光影接入

精简长廊增加真实地面烘焙与物理天空后，共同舞台的原地面、天空分别使用独有材质；源房间材质不变。环境在 prepare/run/render 阶段同步，返回首帧取长廊天空。原生与共同舞台纹理共享，销毁舞台仅释放其自有材质。最新回归为 28 项通过，环境记录见 [GALLERY_ATMOSPHERE_V1.md](GALLERY_ATMOSPHERE_V1.md)。
